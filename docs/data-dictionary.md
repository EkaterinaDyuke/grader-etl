# Семантический слой проекта

Источник данных — API грейдера, его описание в [api.md](api.md). Ниже — что лежит в таблице и как с этим работать.

## Таблицы

| Таблица | Что содержит | Одна строка = | Период |
|---|---|---|---|
| `grader_attempts` | попытки студентов в грейдере | одна попытка: запуск кода или отправка на проверку | 01.10.2022 — 01.06.2026 |

## Поля

| Поле | Тип | Значение | Особенности |
|---|---|---|---|
| `id` | bigserial | номер строки, генерируется базой | первичный ключ |
| `user_id` | text | хеш пользователя | 32 символа `0-9a-f`; имени и почты нет |
| `oauth_consumer_key` | text | токен клиента | на практике всегда пустая строка |
| `lis_result_sourcedid` | text | идентификатор блока с задачей в LMS | внутри курс, блок и хеш пользователя |
| `lis_outcome_service_url` | text | адрес, куда LMS отправляет оценку | может быть `NULL` (около 6% записей) |
| `is_correct` | boolean | правильная ли попытка | `NULL` для `run` |
| `attempt_type` | text | тип попытки | только `run` или `submit` (ограничение в базе) |
| `created_at` | timestamptz | время попытки | хранится момент времени; сервер отдает его в поясе `Europe/Moscow` |

## Метрики и формулы

- **Попыток всего** = `count(*)`.
- **Доля успешных** = `count(*) filter (where is_correct)` / `count(*) filter (where attempt_type = 'submit')`. Делим только на отправки: у запусков оценки нет.
- **Уникальных студентов** = `count(distinct user_id)`.
- **Активных дней** = `count(distinct created_at::date)`.

## Известные ловушки

- Повторная выгрузка не создает дублей: `UNIQUE` плюс `ON CONFLICT DO NOTHING`.
- Записи без `user_id` (около 4 в сутки) в таблицу не попадают — их видно только в логе.
- `is_correct` у `run` равен `NULL`: если считать долю успешных по всем строкам, значение будет заниженным.
- `oauth_consumer_key` всегда пустая строка — фильтр «не пусто» отбросит всю таблицу.
- Время в API в UTC, но сервер базы настроен на `Europe/Moscow`, поэтому в запросах `created_at` уже московское. Если нужен UTC — `SET TIME ZONE 'UTC';` в своей сессии, данные при этом не меняются.
- Примерно 6% записей без `lis_outcome_service_url` — это не ошибка выгрузки, так приходит.

## Связи

Одна таблица, внешних связей нет. `user_id` — хеш, отдельной таблицы пользователей нет, поэтому имена и почту получить нельзя.
