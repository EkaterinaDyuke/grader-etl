# data\raw — исходные данные (только чтение)

Здесь лежат данные в том виде, в каком вы их получили. Это **точка опоры**:
если что-то сломалось, всегда можно начать заново.

Правила:

- Не изменяйте файлы в этой папке вручную и не давайте агенту их перезаписывать.
- Любая очистка, объединение, переименование столбцов — это скрипт, который
  читает `data\raw` и пишет в `data\processed`. Тогда результат воспроизводим.
- Не удаляйте исходники после «успешного» прогона.
- Если датасет большой или приватный — храните его вне git и опишите в
  `README.md` проекта, как его получить.

В git эта папка не попадает (см. `.gitignore`). Маленькие обезличенные примеры
для репозитория кладите в `data\samples`.
